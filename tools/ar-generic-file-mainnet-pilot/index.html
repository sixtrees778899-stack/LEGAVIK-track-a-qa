CJAS 单文件 Mainnet Pilot

1. 选择文件

2. 浏览器本地加密

3. 保存恢复材料

主网独立恢复需要同一次创建生成的 Recovery Kit + Mainnet Recovery Evidence + Recovery Password。

Local Encrypted Backup / 本地加密备份不是正常 Mainnet 恢复必需材料；建议额外保存，Mainnet 暂时不可用时可作为离线加密备份。

取得 TxID 后按钮立即启用。请点击按钮并完成浏览器保存；页面仅在文件真正写入完成后显示“已保存”。

4. Arweave Mainnet 报价

报价仅读取钱包公开地址、余额及当前网关价格。

报价不超过 0.12 AR 且当前文件从未广播时，方可请求一次签名。

5. 经授权后单次广播

仅在当前文件、Archive SHA-256 和费用获得明确授权后使用。按钮只能请求一次签名和一次广播。
