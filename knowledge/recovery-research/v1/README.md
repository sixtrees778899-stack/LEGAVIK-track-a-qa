# CJAS Digital Asset Recovery Knowledge Base v1

本目录把官方恢复资料转化为“陌生但依法或依约获授权的恢复人”可执行的知识。它不是法律、税务或平台客服意见，也不替代平台当时有效的官方流程。

## Pilot 5 scope

- Centralized Exchanges / Custodians：Binance、Coinbase
- Software Wallets / Hot Wallets：MetaMask
- Hardware Wallets / Cold Wallets：Ledger、Trezor
- 后五类与 Batch 1 其余平台尚未研究。

## 使用规则

1. 先确认平台、账户/地址与托管模型，再选择恢复路径。
2. A/B 级结论可作为后续模板候选；C 级须人工评审；D 级不得进入模板。
3. 只在 Recovery Map 记录秘密“存在性”和“查找位置”，不得记录秘密原文。
4. 访问、找回、身份验证、转账控制和死亡/失能流程必须分别判断。
5. 每次执行前重新访问官方页面；政策可能随地区、账户配置、产品与时间变化。
