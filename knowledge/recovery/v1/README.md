# CJAS Recovery Knowledge Base v1

本目录是 CJAS Recovery Map、Guidance、Recovery Review、帮助中心及未来 AI Support 的唯一正式知识来源候选。Batch 1 只建立文档知识，不接入产品代码。

## Modules

- `01-platforms/`：平台事实，统一18节。
- `02-templates/`：按托管模型组合恢复地图。
- `03-rules/`：独立、可引用的恢复规则。
- `04-guidance/`：独立填写指导。
- `05-ai-support/`：只能引用本知识库的客服问答。
- `06-sources/`：官方来源、检查日期及证据等级。
- `07-matrix/`：跨平台条件对照。
- `08-open-questions/`：C/D级问题，禁止进入产品模板。
- `09-atomic-knowledge/`：可独立检索、按claim绑定来源的知识项。
- `10-quality-audit/`：Pilot 5深度质量抽查。
- `11-product-template-candidates/`：17个平台候选模板；未接入产品。

`MIGRATION_AND_AUTHORITY.md`规定本目录是唯一产品知识权威源；旧`knowledge/recovery-research/v1/`仅为Pilot归档。

## Evidence gate

A/B 只能成为产品候选；只有生命周期为`APPROVED`且未过期的Atomic Item才可进入产品。C 必须人工评审；D 只能留在 Open Questions。平台政策执行前必须重新访问官方来源。禁止把完整密码、PIN、OTP、助记词、私钥、Passphrase或全部控制条件写入CJAS。
