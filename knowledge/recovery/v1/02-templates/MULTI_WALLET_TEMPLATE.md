# Multi Wallet Template

Status: `REVIEWED_CANDIDATE`; advanced candidate, not the default personal recommendation and not product-connected.

用于一个恢复计划同时包含多个交易所、软件钱包和硬件钱包。

1. 每项资产只引用其真实控制条件，不共享含义不明的“总密码”。
2. 标记托管、自托管、热钱包、冷钱包和高级多签边界。
3. 记录分散目的、资产角色、目标链和恢复优先级，不记录实时投资建议。
4. 条件、设备和备份位置避免单点；同时避免复杂度超过恢复人能力。
5. 恢复顺序默认：确认法律权限→只读盘点→恢复低风险入口→验证地址→小额测试→分批操作。
6. 多签只作为高级配置入口，不作为普通个人默认推荐。
