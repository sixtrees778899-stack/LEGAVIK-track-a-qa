# Hardware Wallet Recovery Template

Status: `REVIEWED_CANDIDATE`; not product-connected.

1. 型号、固件/创建时期线索、配套应用、公开账户和链。
2. 原设备、PIN、钱包备份、Passphrase分别记录作用和位置。
3. 记录备份标准、词数或份额门限；不保存任何词或份额内容。
4. 记录Passphrase是否启用；启用时必须有分离的位置记录。
5. 设备损坏/遗失时列出官方兼容恢复路径。
6. 恢复后先验证地址和设备显示，再小额测试。
7. 设备真实性、固件警告、电脑索取秘密或地址不一致时停止。
