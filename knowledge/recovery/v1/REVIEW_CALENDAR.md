# Review Calendar

Baseline date: 2026-08-02.

| Knowledge class | Maximum interval | Triggered review |
|---|---:|---|
| Account recovery, 2FA reset, withdrawal lock, estate/legal | 90 days | Any policy/product/region change |
| Self-custody recovery, Passphrase, backup format, device reset | 180 days | Firmware/app/model or recovery-flow change |
| Security stop condition and secret handling | 180 days | New official security advisory |
| CJAS guidance derived from approved facts | 180 days | Any dependency becomes stale |
| Strategy and neutral educational material | 365 days | Material custody-model change |

Next scheduled dates: high-risk CEX claims `2026-10-31`; self-custody and security claims `2027-01-29`; strategy `2027-08-02`.

The calendar is a maximum, not a promise of validity through the date. Review occurs sooner when a link fails, page content changes, products are renamed, regions diverge or official instructions conflict.
