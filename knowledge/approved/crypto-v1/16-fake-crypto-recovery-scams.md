# 如何识别虚假的 Crypto 恢复服务、客服和“资产找回”骗局？

**Status：PUBLISHED**

## 快速了解

任何主动联系并承诺“保证找回资产”、要求预付解冻费、索取核心秘密、要求安装远程控制软件或指示转账到“安全钱包”的人，都应视为高风险。停止联系，通过平台或钱包官方网站独立进入 Support，并保存证据。私人恢复公司不能自行签发冻结或扣押加密资产的法律命令。

## 详细说明

Crypto 恢复骗局常针对已经焦虑或遭受损失的人。常见身份包括：

- 假交易所客服；
- 假钱包厂商 Support；
- 假执法、监管或政府人员；
- 假律师或调查机构；
- 假链上追踪专家；
- 假“白帽黑客”；
- 假资产追回公司；
- 社交媒体中的“成功受害者推荐”。

常见诱导方式包括：

- 承诺一定能找回被盗资产；
- 要求预付调查费、税费、保证金或解冻费；
- 声称需要 Seed Phrase、Private Key 或 Passphrase 才能调查；
- 要求提供 OTP、2FA Code 或 Authenticator Setup Key；
- 要求安装远程控制软件；
- 要求把资产转到新的“安全地址”；
- 使用伪造工单、徽章、证件或官方 Logo；
- 声称与警方、法院、交易所或监管机构有特殊关系；
- 要求持续追加费用。

澳大利亚 Scamwatch 明确警告，Money Recovery Scam 会再次针对先前受害者，以费用、税款或调查款为由承诺追回包括 Cryptocurrency 在内的资金。[Scamwatch：Money recovery scams](https://www.scamwatch.gov.au/types-of-scams/money-recovery-scams)

美国 FBI/IC3 也指出，私人恢复公司不能签发扣押命令；交易所只会依据内部流程或正式法律程序冻结账户。[FBI/IC3：Cryptocurrency recovery schemes](https://www.ic3.gov/PSA/2023/psa230811)

## 客户应该怎么做

### 1. 立即停止互动

如果对方索取秘密、远程访问、付款或转账：

- 不回复；
- 不点击链接；
- 不下载软件；
- 不共享屏幕；
- 不支付费用；
- 不签署交易；
- 不发送资产。

### 2. 独立核验身份

不要使用对方提供的电话号码或链接。自行打开：

- 平台官方 App；
- 官方 Help Center；
- 钱包厂商官方网站；
- 监管或警方正式网站。

通过独立入口确认是否存在该工单、人员或案件。

### 3. 检查典型红旗

- 主动通过 Telegram、WhatsApp、Discord、短信或私信联系；
- 使用紧急、恐吓或保密话术；
- 保证恢复成功；
- 要求付款后才能“释放资产”；
- 要求把资产发送到新钱包；
- 要求 Seed Phrase、Private Key、Passphrase 或验证码；
- 要求远程控制设备；
- 声称能绕过平台或法律限制。

### 4. 保存非秘密证据

可以保存：

- 对方账号和联系方式；
- 网站域名；
- 钱包公开地址；
- 交易哈希；
- 付款要求；
- 消息和邮件；
- 时间线；
- 广告或搜索结果截图。

不要把高敏感材料加入证据包。

### 5. 通过正式渠道报告

根据情况联系：

- 目标交易所或钱包官方 Support；
- 银行或支付机构；
- 当地警方；
- Scamwatch；
- 适用的网络犯罪或监管报告入口。

### 6. 疑似已经泄露秘密时升级

如果已经发送核心秘密、安装远程控制软件、签署未知授权或发生未知转出：

`NEEDS REVIEW / HUMAN ESCALATION`

## 注意事项

- 付费服务、律师或链上分析公司并不当然是骗局，但其身份、能力、收费和法律权限必须独立核验。
- 任何“100% 找回”“内部解冻”“保证追回”都属于重大风险信号。
- 正规的交易所、钱包或硬件钱包客服不应要求客户提供 Seed Phrase、Private Key、额外 Passphrase 或 Authenticator Setup Key 来查看普通支持问题。
- 不要因对方知道姓名、余额、交易哈希或旧工单就认定其真实。
- 资产疑似被盗、核心秘密泄露或恶意授权：`NEEDS REVIEW / HUMAN ESCALATION`。
- 司法、监管、冻结或法律追偿：`NEEDS REVIEW / HUMAN ESCALATION`。

## Needs Review

- 任何具体付费恢复公司、律师、调查机构或链上分析服务必须单独尽调。
- 已发生资产损失、秘密泄露、远程控制或恶意授权时必须 Human Escalation。
- 法律追偿、冻结、扣押和跨境报告不在本文中形成确定性结论。
- 本文不评估资产追回成功率，也不推荐任何第三方恢复服务。
